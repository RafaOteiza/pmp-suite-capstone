## 4. Validación manual

El recorrido controlado actual ha cubierto:

```text
instalación
→ falla
→ retiro
→ Bodega
→ Laboratorio
→ asignación
→ diagnóstico
→ reparación
→ prueba
→ cierre técnico
→ salida Lab→Bodega
```

No se declara todavía validado manualmente el cierre completo QA→Bodega→reinstalación.

## 6. Criterio de cierre

La entrega final debe demostrar coherencia entre:

- problema;
- AS-IS/TO-BE;
- requisitos;
- arquitectura;
- datos;
- implementación;
- pruebas;
- evidencia;
- presentación.

Una función no se marca como validada si solo existe código sin evidencia.
