# Checklist histórico de desarrollo de Bodega

> **ARCHIVO HISTÓRICO.** Este checklist documenta una etapa anterior y no representa el contrato vigente de Bodega/IN/QA. Para arquitectura actual usar `02_Arquitectura/`, `01_Requerimientos/` y `08_Pruebas/`.

Las tareas que aquí aparecían como completadas fueron parte de la evolución del sistema. Varias decisiones cambiaron posteriormente:

- la IN ya no se crea durante recepción QA;
- se crea al confirmar despacho físico hacia Terreno;
- QA usa custodia y flujo autónomo;
- stock directo está protegido;
- Admin ya no hereda operaciones físicas.

Conservar este archivo únicamente como evidencia histórica del desarrollo.
