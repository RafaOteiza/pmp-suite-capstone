# UX y Experiencia por Rol — V2.0

## Principios

- proceso operacional = página/panel inline;
- evitar modales de negocio;
- autocompletado de relaciones conocidas;
- campos derivados readonly;
- estados semánticos consistentes;
- claro/oscuro;
- responsive 320–1440 px;
- error ≠ vacío ≠ cero.

## Experiencia por rol

| Rol | Experiencia |
|---|---|
| Admin | Supervisión global, OS, trazabilidad, usuarios |
| Gerente | Dashboard ejecutivo y consultas |
| Jefe Laboratorio | Resumen Lab, recepción, carga, equipos, despacho |
| Logística | Dashboard Bodega, recepciones, inventario, repuestos, retiros |
| QA | Mi trabajo QA por etapas |
| Técnico Lab | Mi carga, diagnóstico/reparación/pruebas |
| Técnico Terreno | Mi jornada, Mis OS, instalación/retiro/falla |

## Mobile

Incluye perfil, contraseña y tema Automático/Claro/Oscuro. El historial de Terreno expone únicamente contexto técnico y oculta datos administrativos.

## Diseño

Marca PMP Suite: Navy `#0D1B2A`, Azul `#1565C0`, Turquesa `#00B4B0`. Semántica: verde éxito, ámbar pendiente, rojo error/crítico, azul información/proceso, gris inactivo/sin datos.

## Pendiente UX conocido

El editor de Usuarios y accesos aparece debajo de la tabla. Es funcional, pero su apertura debe mejorar con scroll/foco o patrón equivalente.
