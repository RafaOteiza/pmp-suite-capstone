# PMP Suite — Brand Kit V2.0

**Versión documental:** V2.0

## 1. Identidad

La marca PMP Suite debe mantenerse consistente en Web, Mobile, documentos y presentaciones.

Eslogan:

**CONTROL. MAINTAIN. MOVE FORWARD.**

## 2. Paleta principal

| Color | HEX | Uso |
|---|---|---|
| Navy | `#0D1B2A` | navegación/fondos oscuros |
| Azul | `#1565C0` | primario/acción |
| Turquesa | `#00B4B0` | conectividad/acento |
| Gris | `#6B7280` | texto secundario |
| Gris claro | `#E5E7EB` | bordes/divisores |

## 3. Semántica

- verde → éxito/disponible/aprobado;
- ámbar → pendiente/advertencia;
- rojo → error/bloqueo/crítico;
- azul → información/proceso;
- gris → inactivo/sin datos.

Color nunca debe ser la única señal.

## 4. Logos

Carpetas:

- logos principales;
- secundarios;
- apilados;
- isotipo;
- app icons;
- favicons.

Preferir SVG cuando exista y PNG según destino.

## 5. Temas

Claro/Oscuro mantienen:

- identidad;
- contraste;
- semántica;
- jerarquía.

Mobile agrega modo Automático.

## 6. Densidad

Web utiliza densidad compacta sin aplicar `zoom` CSS global.

Mobile conserva targets táctiles de 44–48 pt.

## 7. Componentes

Tokens se aplican a:

- botones;
- inputs;
- KPI;
- badges;
- banners;
- cards;
- tablas;
- estados vacíos.

## 8. Prohibiciones

- recolor arbitrario del logo;
- deformar proporciones;
- usar paletas genéricas que sustituyan PMP;
- comunicar estado solo mediante color.
