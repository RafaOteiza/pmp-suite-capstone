# PMP Suite — Brand Kit

**Versión documental:** V2.0

Identidad visual oficial para Web, Mobile, documentación y presentaciones.

## Paleta
- Navy `#0D1B2A`
- Azul `#1565C0`
- Turquesa `#00B4B0`
- Gris `#6B7280`
- Gris claro `#E5E7EB`

## Semántica
Verde = correcto/listo; ámbar = pendiente/atención; rojo = error/crítico; azul = información/en curso; gris = sin datos/inactivo.

No reemplazar la identidad PMP por paletas genéricas.
